# Life expectancy, fertility, and CO₂ by world region

A small, fully reproducible descriptive analysis for STAT 266A (UC Santa Cruz, Fall 2026).

**To run it, open [`run-analysis.qmd`](run-analysis.qmd) and follow it.** In short:

1. Open this folder in Positron (*File → Open Folder*).
2. In the R console: `renv::restore()`
3. In the terminal: `quarto render run-analysis.qmd`

The rendered `run-analysis.html` explains every step, and doubles as a Quarto tutorial.
Data sources and licenses are in [`data/README.md`](data/README.md).

**Starting your own runbook?** Copy [`template/run-analysis-template.qmd`](template/run-analysis-template.qmd) into your project.
